# Bundled fonts

The app's typefaces, bundled so the PWA keeps its look offline and never has
to go online for a font. Latin subset, woff2, from Google Fonts. All are
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

| File | Family | Used for |
|---|---|---|
| `fraunces-normal.woff2`, `fraunces-italic.woff2` | Fraunces | Mat labels, signs, the menu card |
| `caveat-normal.woff2` | Caveat | Chalk and handwriting |
| `inter-normal.woff2` | Inter | Game UI and body text (`styles/tokens.css`) |
